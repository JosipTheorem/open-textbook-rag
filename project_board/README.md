# Project board

A local web board for tracking this project's tasks. Edits are saved to the Git-tracked `tasks.json` file.

From the repository root, start it with:

```powershell
.\.venv\Scripts\python.exe .\project_board\run_board.py
```

Open `http://127.0.0.1:8765/project_board/`. Stop the server with `Ctrl+C`.
